# agents-manager (`am`)

[🇺🇸 English](README.md) | [🇰🇷 한국어](README.ko.md)

`agents-manager` (CLI command: `am`) is a lightweight, Go-based CLI tool designed for macOS that aggregates, queries, and searches conversation session logs from various AI agents running on your system.

Built entirely with the Go standard library with zero external dependencies, it operates quickly and efficiently without requiring any background daemons or caching. It works simply by directly parsing the local log files generated by each agent.

---

## 🚀 Key Features

### 1. Unified AI Agent Log Collection
Scans the conversation history logs stored on disk by various agents to compile a comprehensive session list.
* **codex**: Parses `~/.codex/session_index.jsonl` and individual session rollout logs (recovers project CWD and the initial user message).
* **claude code**: Parses project logs in `~/.claude/projects/*/*.jsonl` (recovers the last update time of the session and CWD).
* **cursor-agent**: Parses logs in `~/.cursor/projects/<projectDir>/agent-transcripts/` (filters out `<user_query>` tags from titles).

### 2. Session List Query and Merged Sorting
* By default, sessions are queried in a table format and grouped by provider (agent).
* When you provide a directory path filter (`am sessions <dir>`), it merges sessions from all agents that were active in that directory into a single table, sorted chronologically by the most recent updates.

### 3. Transcript Text Search (`am search`)
* Performs keyword searches across the entire text (transcripts), titles, and project roots of all agent sessions.
* Search results are displayed cleanly line-by-line, including snippets of the matching conversation context.

### 4. Interactive TUI (Terminal User Interface)
* When querying session lists in a TTY environment, an interactive TUI mode is launched by default. It displays up to 10 sessions at the bottom of the screen.
* You can navigate through sessions using the `↑/↓` (or `k/j`) keys, and press `Enter` to output the selected session ID to standard output (stdout).

### 5. Telegram Remote Bridge (`am remote`)
* Spawns `codex app-server --stdio` as a child process and acts as a bridge to exchange messages via the Telegram Bot API.
* Currently, it only supports passing the Telegram token directly via a flag.

## 🛠 Installation & Build

### Direct Installation via Go Toolchain
If you have Go installed, you can instantly build and install the binary globally on your system using the following command:
```bash
go install github.com/es-studio/agents-manager@latest
```

### Manual Build from Source
You can also clone the repository locally and build it manually.
```bash
git clone https://github.com/es-studio/agents-manager.git
cd agents-manager
go build -o am am.go
```

## 📖 CLI Command Reference

### Query Session History (`am sessions`)
```bash
# Query the latest 20 sessions globally (grouped by provider)
am sessions

# Query and merge sessions targeting a specific project directory
am sessions /Users/eunsung/dev/my-project

# Combine options (disable TUI, limit output rows, etc.)
am sessions --no-tui --limit 10
```

### Search Conversation Transcripts (`am search`)
```bash
# Keyword search (case-insensitive by default)
am search "error message"

# Case-sensitive search
am search "NullPointerException" --case-sensitive
```

### Telegram Remote Bridge (`am remote`)
```bash
am remote --telegram <bot-token>
```

### Global Options
* `--provider P`: Filter results by a specific provider (e.g., `--provider claude --provider codex`).
* `-n, --limit N`: Maximum number of sessions to display per provider or in a merged view (default: 20).
* `-p, --period D`: Filter sessions by the most recent D days (default: 7 days).
* `--all`: Show all records by disabling both the limit (-n) and period (-p) filters.
* `--json`: Output the results in JSON format (useful for script integrations).
* `--debug`: Print debug logs during the scanning and parsing process.

### `remote` Options
* `--telegram <token>`: Uses the Telegram Bot API token to bridge Telegram messages with the Codex app-server.
